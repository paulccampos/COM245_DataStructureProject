4. Data Structure Used

DATA STRUCTURES ANALYSIS:

1. **Queue (Used)**:
   - **Purpose**: Manages the playback queue for songs, allowing FIFO (First-In-First-Out) order for sequential playback. Supports manual additions (user-added songs) and auto additions (recommendations). Prioritizes manual songs over auto songs.
   - **Why Queue instead of others?**: Queue is ideal for sequential playback where songs are played in the order they are added. Unlike a stack (LIFO), it ensures songs are played in the intended sequence. Not a priority queue since manual songs have priority over auto, but it's handled by insertion logic rather than priority values. Not a list because queue semantics (enqueue/dequeue) fit the use case better.
   - **Code Snippet** (from Queue.java):
     ```
     public void addSong(Song song, Type type) {
         if (type == Type.MANUAL) {
             int lastManual = -1;
             for (int i = types.size() - 1; i >= 0; i--) {
                 if (types.get(i) == Type.MANUAL) {
                     lastManual = i;
                     break;
                 }
             }
             int insertIndex = lastManual + 1;
             songs.add(insertIndex, song);  // Insert at index for priority
             types.add(insertIndex, type);
         } else {
             // Auto songs added after manual, sorted by play count
         }
     }
     ```
     - **Explanation**: Inserts manual songs after the last manual song for priority. Auto songs are sorted by global play count.

2. **Stack (Not Used)**:
   - **Why not used?**: The project doesn't require LIFO (Last-In-First-Out) operations. Playback is sequential, not reverse-order. A stack would be unsuitable for queue management.

3. **Priority Queue (Not Used)**:
   - **Why not used?**: While there is prioritization (manual over auto(shuffle and suggestions)), it's not based on dynamic priorities like play counts for all songs. Instead, it's a simple rule: manual first, then auto sorted by play count. A priority queue would be overkill and less efficient for this fixed prioritization.

4. **List/ArrayList (Used extensively)**:
   - **Purpose**: Stores collections of songs, playlists, users, etc. Used for dynamic arrays in queues, playlists, and UI lists.
   - **Why List instead of others?**: Provides flexibility for insertions, deletions, and access by index. Better than arrays for dynamic sizing. Not a set (no uniqueness needed), not a map (no key-value pairs).
   - **Code Snippet** (from songscontroller.java):
     ```
     List<Document> songs = mongoService.getAllSongs();
     String selectedGenre = genreComboBox.getValue();
     if (selectedGenre != null && !"All Genres".equals(selectedGenre)) {
         songs.removeIf(song -> {

             } else if (genreObj instanceof String) {
                 String songGenre = (String) genreObj;
                 return songGenre == null || !songGenre.equals(selectedGenre);
             }
             return true;
         });
     }
     ```
     - **Explanation**: Loads all songs into a List, then filters the list by removing songs that don't match the selected genre, allowing dynamic UI updates based on user selection.

5. **HashSet (Used in recommendations)**:
   - **Purpose**: Ensures uniqueness in added titles during recommendation generation.
   - **Why HashSet?**: Fast lookups for uniqueness checks. Better than List for preventing duplicates in recommendations.
   - **Code Snippet** (from MediaPlayerService.java):
     ```

     addedTitles.add(currentSong.getTitle());
     // Later: if (!addedTitles.contains(song.getTitle())) { ... }
     ```
     - **Explanation**: Prevents duplicate recommendations by checking if a song title is already added.

1. **Sorting (Quicksort in songscontroller.java)**:
   ```
   private void quickSort(List<Document> list, int low, int high, String key) {
       if (low < high) {
           String pivot = list.get(high).getString(key);
           int i = low - 1;
           for (int j = low; j < high; j++) {
               if (list.get(j).getString(key).compareTo(pivot) <= 0) {
                   i++;
                   Document temp = list.get(i);
                   list.set(i, list.get(j));
                   list.set(j, temp);
               }
           }
           Document temp = list.get(i + 1);
           list.set(i + 1, list.get(high));
           list.set(high, temp);
           int pi = i + 1;
           quickSort(list, low, pi - 1, key);
           quickSort(list, pi + 1, high, key);
       }
   }
   ```
   - **Explanation**: Recursive quicksort for sorting songs by title or artist. Efficient for large lists (O(n log n) average). Used instead of built-in sort for custom implementation, likely for educational purposes.

1. Password Strength Validation Implementation (SignUpController.java):
   - Real-time password strength checker with progress bar and label.
   - Scoring based on length (8-25+ chars), character types (lowercase, uppercase, digits, special chars).
   - Penalties for sequential chars, repeated chars, common words.
   - Requires "Good" or better (score >= 41) to enable signup button.
   - Code Snippet:
     ```
     private int calculatePasswordStrength(String password) {
         int score = 0;
         // Length bonus
         if (password.length() >= 8) score += 10;
         if (password.length() >= 12) score += 10;
         if (password.length() >= 16) score += 10;
         if (password.length() >= 20) score += 10;
         if (password.length() > 25) score += 5;

         // Character type bonuses
         if (password.matches(".*[a-z].*")) score += 10; // lowercase
         if (password.matches(".*[A-Z].*")) score += 10; // uppercase
         if (password.matches(".*[0-9].*")) score += 10; // digits
         if (password.matches(".*[^a-zA-Z0-9].*")) score += 10; // special chars

         // Penalties
         if (password.matches(".*(.)\\1{2,}.*")) score -= 10; // repeated chars
         if (password.matches(".*(abc|bcd|cde|def|efg|fgh|ghi|hij|ijk|jkl|klm|lmn|mno|nop|opq|pqr|qrs|rst|stu|tuv|uvw|vwx|wxy|xyz|012|123|234|345|456|567|678|789).*")) score -= 10; // sequential
         String[] commonWords = {"password", "123456", "qwerty", "admin", "letmein"};
         for (String word : commonWords) {
             if (password.toLowerCase().contains(word)) {
                 score -= 20;
                 break;
             }
         }

         return Math.max(0, score); // Ensure non-negative
     }
     ```
     - **Explanation**: This method calculates a password strength score by awarding points for length and character variety, while deducting points for weaknesses like repeated characters, sequential patterns, or common words. The score determines the strength level displayed to the user and enables the signup button only if strong enough.

2. Auto-Suggest Recommendations Implementation (MediaPlayerService.java):
   - This method adds recommendations to the queue when it's empty, prioritizing songs with matching artist, genre, and vibe, then genre and vibe, using HashSet for uniqueness, sorting by ascending global play count.
   - Code Snippet:
     ```
     private void addRecommendations(Song currentSong) {
         List<Song> recommendations = new java.util.ArrayList<>();
         java.util.Set<String> addedTitles = new java.util.HashSet<>();
         addedTitles.add(currentSong.getTitle());

         List<org.bson.Document> allSongs = mongoService.getAllSongs();
         List<Song> allSongModels = allSongs.stream().map(Song::new).collect(java.util.stream.Collectors.toList());

         java.util.List<String> currentGenres = getStringList(currentSong, "genre");
         java.util.List<String> currentVibes = getStringList(currentSong, "vibe");
         String currentArtist = currentSong.getArtist();

         // Priority 1: Same vibe AND genre AND artist
         for (Song song : allSongModels) {
             if (!addedTitles.contains(song.getTitle())) {
                 java.util.List<String> songGenres = getStringList(song, "genre");
                 java.util.List<String> songVibes = getStringList(song, "vibe");
                 String songArtist = song.getArtist();

                 if (currentArtist != null && currentArtist.equals(songArtist) &&
                     hasCommonElements(currentGenres, songGenres) &&
                     hasCommonElements(currentVibes, songVibes)) {
                     recommendations.add(song);
                     addedTitles.add(song.getTitle());
                 }
             }
         }

         // Priority 2: Same vibe AND genre
         if (recommendations.size() < 20) {
             for (Song song : allSongModels) {
                 if (!addedTitles.contains(song.getTitle())) {
                     java.util.List<String> songGenres = getStringList(song, "genre");
                     java.util.List<String> songVibes = getStringList(song, "vibe");

                     if (hasCommonElements(currentGenres, songGenres) &&
                         hasCommonElements(currentVibes, songVibes)) {
                         recommendations.add(song);
                         addedTitles.add(song.getTitle());
                     }
                 }
             }
         }

         recommendations.sort((a, b) -> Integer.compare(a.getGlobalPlayCount(), b.getGlobalPlayCount()));

         for (Song rec : recommendations) {
             addAutoToQueue(rec);
         }
         System.out.println("Added " + recommendations.size() + " recommendations to queue.");
     }
     ```
     - **Explanation**: This method generates personalized song recommendations by matching the current song's artist, genre, and vibe in priority order, ensuring no duplicates via HashSet, sorting by play count, and auto-adding to the queue for continuous playback.

               return;
           }

           ChoiceDialog<Document> dialog = new ChoiceDialog<>(playlists.get(0), playlists);
           dialog.setTitle("Add to Playlist");
           dialog.setHeaderText("Select a playlist to add the song to:");
           dialog.setContentText("Playlist:");

           Optional<Document> result = dialog.showAndWait();
           result.ifPresent(playlist -> {
               if (!mongoService.isSongInPlaylist(song, playlist)) {
                   mongoService.addSongToPlaylist(song, playlist);
                   // Show success message
               } else {
                   // Show duplicate message
               }
           });
       }
